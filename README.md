# ⚡ ElectraCAD Studio

**ブラウザで動く電気設計CAD** — EPLANライクな回路図作成・AI自動作図・通電シミュレーションをインストール不要で。

## 起動方法

`electracad/index.html` をブラウザで開くだけです(サーバー不要・依存ゼロ・完全オフライン動作)。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| **AI自動作図** | インプット機器 → ロジック機器 → アウトプット機器 を選ぶだけで、電気設計のセオリー(安全チェーン直列・起動並列/停止直列・自己保持・接点数管理)に基づく制御回路を自動生成。モータ選択時は主回路ページ(**三相3極 / 単相2極** とも遮断器・電磁接触器・サーマルリレー・接地・相番号つき)を自動追加。図枠に収まらない回路は複数ページに自動分割し電位リンクで接続 |
| **AutoCAD / PDF出力** | ファイルメニューから **DXF出力(AutoCAD互換・全ページ)**、**PDF出力(全ページ印刷→「PDFに保存」)** |
| **未登録機器** | 「汎用機器(2端子/4端子)」を配置し、プロパティで機能テキスト・型式を設定。既存シンボルもタグ/型式を自由に変更可能 |
| **IEC 60617 シンボル** | 押しボタン/非常停止/センサ類、リレー/タイマ/PLC、モータ/ランプ/電磁弁、遮断器/PSU など約30種。5mmグリッドに整列 |
| **回路エディタ** | 直交配線(ピンスナップ・T接続ジャンクション)、移動時の自動再ルーティング、回転、コピペ、Undo/Redo、複数ページ |
| **通電シミュレーション** | F5で実行。ボタンやスイッチをクリックすると通電経路を色表示。自己保持・オン/オフディレイタイマ・非常停止が実挙動どおり動く |
| **クロスリファレンス** | コイル下に連動接点の位置一覧(接点ミラー)、接点側には親コイルの位置(ページ.列)を自動表示 |
| **PLC入出力結線図** | キーエンス KV Nano (KV-N14AT / KV-N24AT / KV-N40AT) を実務の結線図の形で用意。用紙 1 枚 = 1 群 (16 点まで)。「下地を作る」でレールと各行の分岐を実線で引き、機能欄は行ごとに書ける。→ [使い方](#plc-入出力結線図の使い方) |
| **行き先 (継続先)** | 回路の続きが描いてある葉を指す旗。図面番号はプロパティのプルダウンで選んだページのものを自動表示し、ページの並べ替え・図番の振り直しに追従。→ [使い方](#行き先-継続先-の使い方) |
| **配線番号** | 接点・コイルを跨がない区間単位で自動採番。+24V/0V は電位名 |
| **DRC(検図)** | 未接続ピン・タグ重複・リンク未設定接点・電源未到達などを自動検出、クリックで該当箇所へジャンプ |
| **部品表** | デバイスタグ集計・型式・数量を自動生成、CSV出力 |
| **図面出力** | A3図枠・表題欄・列行参照つき。SVGエクスポート/印刷/JSON保存・読込/ブラウザ自動保存 |

## PLC 入出力結線図の使い方

キーエンス KV Nano シリーズの基本ユニットを、実務の入出力結線図の形で用意しています。

```
+24V ┃ 0V ┃                             ┌──────────┐
     ┃    ┣━━[ 機器 ]━━○─┤R007      │ ── 起動押ボタン ────
     ┃    ┃                             │KV-N24AT  │
     ┃    ┣━━[ 機器 ]━━○─┤R008      │ ── 停止押ボタン ────
     ┃    ┃                             │入力(2/2) │
     ┗━━━━━━━━━━━━━━○─┤COM       │
                                        └──────────┘
 外側=       内側=      現場側    端子   端子名は     機能欄 (下線に書く)
 コモン側     分岐側     (実線)    (小円) 外郭の内側
```

**入力と出力は実機のユニットに合わせて鏡像**です。入力は現場側が左
(レール → 機器 → 端子 → 箱、名称欄は箱の右)。出力は**箱が左**で、
箱 → 端子 → 負荷 → レール、**名称欄は右端** (レールのさらに右) に並びます。

```
┌──────────┐
│KV-N14AT  │
│出力 6点  │
│     R500 ├○──[ 負荷 ]──┃+24V ┃0V   ── 運転表示灯 ──
│     COM  ├○────────────────┃   ── 出力コモン ──
└──────────┘
  ユニット      端子  現場側 (実線)   レール      名称欄
```

シンク形の入出力なので、入力は 0V →接点→ 入力端子、出力は +24V →負荷→ 出力端子と
電流の向きが逆になります。どちらの紙でも **外側 = コモン側 / 内側 = 分岐側**で
位置をそろえてあるので、行の引出しがもう 1 本のレールをまたぎません。

**機器は右 90° (rot 270) で置けば向きが合います** — 入力は左が電源側 (P,N)・右が信号、
出力は左が信号 (出力端子)・右が電源側 (P,N) と、どちらもそのままの向きで
ユニットに刺さります。

**用紙 1 枚 = 記号 1 個** です。1 枚に載せる点数は「A3 横に収まる高さ」で切っています。
チャネル (16 点) はまたがず、1 チャネルを均等に割ります。

**端子の刻印は取扱説明書の入出力回路図どおり**です — デバイス番号 (R000〜/R500〜) から
R を除いた数字が刻印で、コモンは **C0, C1, …**。出力側の端子台には**サービス電源
(0V / 24V)** の端子があり、出力の 1 枚目に載せています (未使用なら黙ります)。

| 機種 | 入力 | 出力 | 枚数 (すべて A3 横・非尺度) |
| --- | --- | --- | --- |
| KV-N14AT | 8点 (000〜007) + C0 | 6点 (500〜505) + COM | 入力 1 枚 + 出力 1 枚 |
| KV-N24AT | 14点 (000〜013) + C0 | 10点 (500〜509) + COM | 入力 2 枚 + 出力 2 枚 (5点ずつ) |
| KV-N40AT | 24点 (000〜107) + C0 | 16点 (500〜515) + COM | 入力 3 枚 + 出力 2 枚 (8点ずつ) |
| **KV-N14AR** | 8点 (000〜007) + C0 | 6点 (500〜505)・**分割コモン C1〜C4** | 入力 1 枚 + 出力 1 枚 |

KV-N14AR は**リレー出力**で、コモンが分割です (C1=500 / C2=501 / C3=502 /
C4=503〜505 — 取説の出力回路図で確認)。図でも群ごとにコモン行が挟まり、
「下地を作る」は**分割コモンを全部 0V レールへ**結びます (リレー出力なので
交流負荷や群ごとの別電源にする図では、引いた下地を手で描き替えてください)。

> **未確認のデータ (取説で確認でき次第 `KV_UNITS` へ)**
> - AT 形の**出力**コモンの刻印 (現状 COM のまま)
> - **N24AT / N40AT の入力コモンの数と刻印** — 「C0 が 1 つ」は N14AR からの類推です
>
> **注意 (複数枚の C0)**: 入力を複数枚に分けた機種では、同じ物理端子 C0 が
> 枚ごとに描かれ、下地もそれぞれレールへ結びます。C0 が実機で 1 端子なら、
> 施工時の渡りは 1 箇所にしてください (図は各枚の結線の意図を示すものです)。
>
- **端子はユニットの中に**: 入出力結線図の端子の丸を、ユニットの外郭の**中**に
  移しました (取説の回路図と同じ「四角の中に丸」)。円は外郭の辺に内側から接し、
  導体は接点で終わって円の中へは入りません。
- **破線枠のリサイズ**: 盤外・グループの破線枠は、選択すると**つまみ (角 4 +
  辺の中央 4)** が出て、マウスでつまんで幅と高さを変えられます (5mm 格子・
  最小 10mm・元に戻すに対応)。

> **通信コネクタの整理**: USB-A/B/C・HDMI のポート記号は削除しました (指示による)。
> 旧図面でそれらを使っていた場合は「未登録シンボル」として検図が知らせます。
> EtherNet/IP (RJ45) は残し、見出しをモジュラジャックの形 (2 段ラッチ + 接点 8 本)
> に描き直しました。通信ポートは**接続が関係ない図**として扱い、シミュレーションの
> 対象外・未配線でも警告なしです。
>
> **図面を旧版で保存している方へ**: KV-N24AT の出力は 1 枚 (`kv_n24at_out`) から
> 2 枚 (`kv_n24at_out1/2`) に分かれました。旧 id で保存した図面はその記号が
> 「未登録シンボル」になり検図が知らせます — 新しい記号に置き直してください。
> ソフト側のデバイス番号 (R000〜/R500〜) は端子の刻印に R を付けたものです。
> 図面単独で対応を示したいときは、機能欄や注記に R 番号を書き添えてください。

> **なぜ 16 点 = 1 枚をやめたか。** 1 行 = 1 機器を横に倒して置くので、行ピッチは
> 機器どうしがぶつからない距離 (20mm) が要ります。16 行だと縦 335mm を超え、A3 には
> どう置いても入りません。用紙を A2 へ上げると、現場に持ち込む図面集が折らないと
> 綴じられず複写機にも乗らないので、**紙ではなく割付のほうを変えました**。
> 結果、どの機種のどの枚も A3 横 1 種類にそろっています。

**ユニットの電源と接地は、この図には入れません。**別紙の電源回路図に描きます。
入出力結線図が受け持つのは「現場機器 ─ 入出力端子」の対応で、電源の供給元・遮断器・
接地の系統は電源回路図で追うものだからです。混ぜるとどちらの図も読みにくくなり、
電源端子の呼びが機種で変わる (交流電源形は L/N、直流電源形は 24V/0V) ぶんの誤りも
持ち込むことになります。補助行は**コモンだけ**です (コモンは行の帰り側なので
入出力結線図の一部)。

用紙は記号の大きさから自動で決まります。判定では、右下でふさがる**表題欄 (160×30) と
その左隣に並ぶ改訂履歴欄 (120×30)**、あわせて幅 280mm の帯を最初から空けています。

### 端子の描き方

- 端子の小円は**外郭に接して**描き、導体は**円の外周で終え**ます。円の中心を外郭線の
  上に置くと、外郭が端子を貫き導体が円の中心まで入った図になります (画面は白塗りで
  隠れても、**DXF にはそのまま出ます**)。
- **端子名は外郭の内側**に書きます。外に出すと、現場側の配線区画に機器のピン番号・
  線番と並んでしまい、読み合わせに手間がかかります。
- **接地の図記号は記号に焼き込みません。** 焼き込むと「紙の上は接地済み・モデルは
  未接続」という食い違いが起き、指示どおり結線すると導体が接地記号を貫き、別に
  接地記号を置けば 2 つ並びます (接地そのものは電源回路図で、
  **保護接地 (02-15-03)** を置いて結びます)。

### 行ピッチ (現場機器がぶつからない距離)

行ピッチの既定は **20mm** です。横に倒した**単極**の現場機器の線どうしが 1mm 以上あく
最小の格子寸法です (15mm では接点どうしが接します)。

| 行ピッチ | 収まる現場機器 (線のあき) | 用紙 |
| --- | --- | --- |
| 15mm | ― (接点どうしが接する) | すべて A3 横 |
| **20mm (既定)** | 押しボタン・セレクタ 5mm / 非常停止 (1NC)・フロート 4mm / リミット 10.4mm / サーモ 5.7mm / 近接・圧力 1mm | **すべて A3 横** |
| 25mm | 上記 + 余裕 | KV-N24AT は A3 縦、他は A3 横 |
| 30〜35mm | **非常停止 (2NC)・光電センサ** も収まる | A3 縦 |

用紙は**機種でそろえます** (その機種でいちばん行数の多い枚に合わせます)。枚ごとに
決めると、ピッチを広げたとき 1 台の図面集に横と縦が混ざり、綴じた図をめくるたびに
紙を回すことになるためです。

**既定ピッチで収まらない機器**: 非常停止ボタン (2NC) は −6mm、光電センサは接します。
どちらも多極・横に長い記号なので、プロパティの **行ピッチ** を 30mm に広げてください
(用紙は自動で選び直し、隙間の機器も一緒に運ばれます。16 点の枚はピッチを広げると
A2 縦になります)。

機能欄 (コメント) の下線は **50mm** です (長すぎたので半分にしました —
はみ出しは画面で分かり、図枠の外へ出れば検図がエラーで知らせます)。

### 描き方

1. パレット (データベース分類「PLC入出力結線図」) から群を選び、**図枠の左寄せ**で置きます。
   入力はレールの左に 10mm ほど、出力は箱の左辺を図枠から 10mm ほど空けてください。
2. **置いた瞬間に P24V / N24V のレール 2 本とコモンの結線だけが実線で引かれます**。
   **行ごとの配線 (端子 ↔ 機器 ↔ レール) は自分で引きます** — 未使用の行に
   宙に浮いた導体が刷られることはもうありません。引き直しはプロパティの
   **結線図の下地を作る** からいつでもできます。
   行ピッチや機種を変えると、**引いた配線と機器は行ごと新しい位置へ運ばれ、
   レールが動けば端点も新しいレールへ付け替えられます**。
3. 行に押しボタン・センサなどを置き、配線を引きます。
   **3 線式センサ (茶/黒/青) は 茶→P24V・青→N24V・黒→端子**です。
   茶を N24V へ引き間違えると「3線式センサの電源が逆」がエラーで知らせます
   (そのまま結線するとセンサが壊れるため)。
   **3 線式の直流検出器 (近接・光電・圧力) は NPN (シンク) 形**で描いてあります —
   開閉要素は「出力と 0V」の間です。「+V と出力」の間 (PNP・ソース形) に描くと、
   プラスコモンの入力につないでも永久に ON しない図になります。
4. **機能欄**はプロパティのテキスト欄に 1 行 1 端子で貼り付けます。記号に焼き込まないので、
   同じ記号を何枚置いても中身は別々です。画面・印刷・DXF に同じ位置で出ます。
5. 機種を変えるときは、プロパティの **機種** プルダウンで同じ群の機種に差し替えます。
   行数が変われば**下地を引き直し、隙間の機器も新しい行へ運びます**。
6. **行ピッチ**を変えると、隙間に置いてある現場機器も新しい行の高さへ一緒に運ばれ、
   下地も引き直されます (機器だけ旧位置に残って全行が外れる、ということはありません)。
7. **規格外図記号の凡例**を押すと、この枠記号の作成根拠を注記として図枠の左下に貼れます
   (JIS C 0617-1: 規格にない図記号は図面上で説明する)。

> 記号は端子より右だけを持ちます。現場側を記号の中に描いてしまうと、見た目はつながって
> いるのに検図もシミュレーションも通らない図になるためです。

### 検図

- 未使用の入出力点は警告しません (全点を使う図面ばかりではないため)。
- **コモンの結び忘れは必ず知らせます** (使わない入出力点と違い、コモンが浮いていれば
  その群は 1 点も動きません)。同じ名前の端子が複数ある場合は、区分 (列・行) を添えて
  どちらかが分かるようにしています。
- 保護接地 (PE) の未接続は**エラー**です — ただし電源回路図側の話で、入出力結線図には
  接地端子はありません (感電保護は PE がつながっている前提のため、他の図で効きます)。
- 機能欄の文言も紙に出る文字として見ます。長すぎて図枠の外へ出たり表題欄に乗ったりすれば
  エラーになり、下線からはみ出した行は画面で分かるようにしています。
- 記号の想定用紙と違うページに置いたときはエラーで知らせます (プロパティの
  「この用紙にする」で合わせられます)。
- **3 線式センサの茶が 0V 側、青が +24V 側**につながっていればエラーです (通電した
  とたんにセンサが壊れるので、未接続より重い誤りとして扱います)。
- **図記号どうしの重なり**と、**図記号を貫く導体**を見ます。判定は bounds ではなく
  記号が実際に線を引いている範囲 (インク) で行うので、端子台のように 5mm ピッチで
  並べた端子は鳴りません。
- 1 台を複数枚に分けて描いたのに、分かれた枚どうしに**行き先**が無いときは警告します。
- 出力の枚で負荷を隙間に置いても検図は 0 件です。負荷の帰りは機器の中 (COM) を通るので
  図の上では電源へ届きませんが、入出力結線図の枠記号の端子につながっていれば
  「そこから先は機器の中」として扱います。
- 空いている行 (使わない入出力点) の隙間の端は「宙吊り」と言いません。全点を使い切る
  図面のほうが珍しいので、毎回 2 件ずつ出ると本当に見るべき指摘が埋もれるためです。

### 尺度と投影法について

**すべて NS (非尺度) です。** 表題欄の**投影法**も既定を「該当なし (回路図)」に
しました。回路図・結線図は図記号で描く図であって正投影図ではないので、投影法を
持ちません (JIS Z 8316 / ISO 5456-2 の図示記号も刷りません)。機械図を取り込んだ
ページなど、必要なページでは表題欄の設定で第三角法に変えられます。
 図記号で表す図は実物との寸法比を持たないので、
「1:1」と刷るのは事実に反します (JIS Z 8314 / IEC 61082-1)。幾何は 1:1 と同じで、
表題欄の表示だけが正しくなります。

縮小尺度 (1:2 など) は使いません。このアプリは図記号を尺度に関わらず実寸で描くため、
1:2 にすると線番・注記・現場機器の記号が用紙の上で半分 (1.25mm) になり、
JIS Z 8313 の最小呼び 2.5mm を下回ります (線番を 1 本振っただけで検図がエラーになります)。

### 端子の呼びについて (要確認)

端子名は KV Nano の内蔵入出力リレー (入力 R000〜 / 出力 R500〜、16 点で次のチャネルへ
繰り上がり) です。次の 3 点は**機種の取扱説明書で必ず確認してください** —
`js/symdb.js` の `mkKvUnit(...)` の定義を書き換えれば、端子構成ごと差し替わります。

- **端子台の刻印**が内部リレー番号と違う機種では、刻印のほうを併記する必要があります
  (IEC 61082-1: 端子は実機に表示されている記号で識別する)。
- **COM の分割**。この実装は 1 枚に COM を 1 つとしています。分割コモンの機種では
  枚ごとの COM 名を実機に合わせてください。

(ユニットの電源端子の呼びは、この図には出てこないので確認の対象外です。
電源回路図側で機種に合わせてください)

## 行き先 (継続先) の使い方

回路が次の葉へ続くことを示す記号です (JIS C 0617 に該当図記号が無いため規格外扱い。
継続の表示そのものは IEC 61082-1 の相互参照)。

1. 「その他」から **行き先** を、続きへ渡る導体の**端**に置きます。
2. プロパティの **行き先** プルダウンで続きのページを選びます。旗の中に、そのページの
   図面番号が出ます。ページを並べ替えても図番を振り直しても表示は自動で追い掛けます。
3. 続きの葉にも行き先を置き、**元の葉を指し返します** (180° 回すと受け側の向きになります)。
   往復で対にすると、旗の図番に相手の**区分 (列と行)** が付いて `E-002/7B` と読めるようになります。
4. **電位リンクを併せて置きます。** 行き先は表示だけで、電気的にはつながりません
   (回路の続きは同じタグの電位リンクが担います)。両側の導体に同じタグのリンクを付けると、
   相互参照の相手も信号で決まります。

作図の目安
- 継続線を並べるピッチは**格子 2 目 (10mm)**。5mm ピッチだと旗の輪郭どうしが接します。
- 図面番号は**欧文**で。和文の図番は最小呼び 3.5mm (JIS Z 8313-10) になり旗に収まりません
  (検図がエラーで知らせます)。

検図で見ているもの: 行き先未設定 (エラー) / 自分の葉を指している (エラー) / 指し先のページが
削除済み (エラー) / 図番が旗に入らない (エラー) / 対が無い・対が定まらない (警告) /
旗どうしが近すぎる (警告) / 電位リンクが無い・リンクの相手が食い違う (警告)。

## 更新履歴 (既存図面に影響する変更)

- **パレットの追加・外すを全記号に**: シンボルデータベースのどのカードにも「✓ 外す / 追加」が付き、どの分類の記号もパレットの棚から外したり戻したりできます (このブラウザに保存)。
- **シンボル作成: グループと分解**: コネクタと「シンボルを挿入…」で取り込んだ記号は**塊 (グループ) で選択・移動**されます。「分解」でほどいて個々の図形を回転・移動でき、グループが無いときは**3点以上の折れ線を線分ごとに分解**します(一部の線だけ回したいときに)。
- **コネクタの再編集**: 配置したコネクタを選んで**「コネクタ編集」**を押すと、極数・ピッチ・信号名などを読み込んだ状態で開き、その場で作り直せます (1P のコネクタも配置・再編集できます)。
- **Esc で選択ツールへ**: 作画中の Esc は作画の中止、それ以外の Esc は選択ツールに戻ります。
- **端子の先端吸着**: 端子ツールは線の端点・弧の両端・矩形の角/辺中点・円の四分点へ **2.5mm 以内で吸着**します(十字線も吸着先に乗る)。強制ではないので、先端から離せば従来どおり 5mm グリッドに置けます。
- **シンボル作成のカーソルを CAD 式の十字線に**: OS の太い十字カーソルをやめ (cursor:none)、作画キャンバスに**髪線 (常に 1px) の十字線とスナップ枠**を描くようにしました。枠の中心がスナップ済みの座標 = 実際にクリックが落ちる点です (端子ツールでは 5mm グリッドに乗って動きます)。キャンバスの外へ出すと消えます。
- **シンボルデータベースにライブラリの全記号を統合**: 「挿入 > シンボルデータベース…」に規格ライブラリを含む全記号 (114 種) が載り、記号ごとに**パレットの分類 (インプット機器 / ロジック機器 / アウトプット機器 …) を入れ替え**られます (このブラウザに保存)。AI自動作図のウィザードも入れ替え後の分類に従います。
- **すべてのシンボルを編集可能に**: データベースの「編集」からどの記号もシンボル作成で開けます。規格記号の body は**個々の線・円・円弧・文字に分解**して編集でき (曲線持ちの数記号だけ塊のまま移動・回転可)、保存すると全域で上書きされます。上書きした規格記号は「自作シンボルの管理」の**「元に戻す」でいつでも規格原本へ復元**できます。寸法違い (多芯ケーブル等) と結線図の下地は自動生成のため**複製として**開きます。
- **シンボル作成の操作追加**: 選択の**複製 (Ctrl+C/X/V/D)**・**90° 回転 (R。未選択なら全体)**・**「シンボルを挿入…」で既存記号を作画へ取り込んで組み合わせ**られます。DXF で読み込んだ図形もそのまま複製・回転できます。
- **重なりの中でも選べるように**: クリックの拾い方を「文字 → 導体 → 破線枠 → 機器」の順にしました。機器の外形箱の中を通る導体 (端子を貫く線・PLCユニットの上の線など) や、機器と重なった破線枠の枠線が選べるようになります。多芯ケーブル・シールドの囲みは**輪郭の近傍だけ**で拾い、囲んだ導体は中で普通に選べます (内側の空白は空クリック)。選択中のものは重なりの中でも優先して拾うので、選択済みの機器を導体ごしにつまんでドラッグできます。
- **多芯ケーブル・シールドのタグ重複を検図しない**: 囲み記号は機器ではなく導体への注記なので、同じ呼び (例 -sq1.25) を何個置いても「デバイスタグ重複」にしません。普通の機器のタグ重複は従来どおりエラーです。
- **DXF 取り込みの文字寸法を原寸に**: DXF を縮小して取り込むと文字だけが 2.5mm へ持ち上がり、図形に対して巨大化して元の見た目と別物になっていました。取り込んだ文字 (ページへの作図・シンボル登録・シンボル編集の読み込みのすべて) は **DXF の文字高 × 倍率をそのまま**使い、和文の最小呼び (3.5mm) への引き上げも行いません (元図に忠実であるべき文字のため。手で置く注記は従来どおり持ち上げます)。旧版で取り込み直すと文字が小さく (=正しく) なります。
- **PLC本体 (plc_box)**: 端子を上側3本の電源端子 AC_L / AC_N / FG に変更 (旧 I0〜I3 / Q0〜Q3 は廃止)。旧版で保存した図面は該当配線が外れ、DRC の「未接続ピン」警告で検出されます — 手動で再配線してください。
- **電源装置 PS (ps_box) / インバータ INV (inverter_box)**: PE 端子を追加 (PS は L–N 間、INV は一次側 R の左)。既存配置では PE が未接続のため DRC 警告が出ます (接地忘れ検出として有効)。INV は箱が左へ 5mm 広がるため、左側に近接する注記との被りを再確認してください。モータフレーム接地は別途作図してください。
- **接地線の線番**: PE / FG などの接地端子につながる配線には連番を振らず、端子名を電位名として印字します。
- **圧力スイッチ (press_sw)**: 電子式3線 (P24V=+24V / N24V=0V / OUT=入力信号線) に変更 (近接・光電センサと同じ構造)。上下の端子座標は従来と同じため既存図面の配線はそのまま生きます。N24V の 0V 配線を追加し、切替接点版 (11/12/14) で 12 に配線していた場合はつなぎ直してください。AI自動作図は N24V を 0V レールへ自動配線します。
- **PLC 入出力結線図から電源・接地を外しました**: ユニットの電源 (L/N) と接地 (PE) は別紙の電源回路図に描くものなので、入出力結線図の補助行は**コモンだけ**にしました。

- **PLC 入出力結線図の作り直し (批評ラウンド 2 の反映)**: **1 枚 = A3 横に収まる行数 (最大 10 点)** に割付を変え、どの機種のどの枚も A3 横 1 種類にそろえました (A2 は現場で綴じられないため、紙ではなく割付を変えました)。尺度表示を **NS (非尺度)** に直し、用紙の判定で改訂履歴欄が**表題欄の左隣**に並ぶことを反映しました。**端子の小円を外郭に接して**描き導体は円の外周で終えるようにし (DXF に貫通が出ていました)、**端子名を外郭の内側**へ移し、**保護接地の図記号は焼き込まない**ことにしました (紙は接地済み・モデルは未接続という食い違いが出るため)。下地は**レール 2 本を離し・両端に電位を表示・コモンを自動結線・3 線式センサを正しく引き分け**、空いている行の隙間を「宙吊り」と言わなくなりました。行ピッチを変えると**隙間の機器も一緒に運ばれます**。検図に **図記号どうしの重なり / 図記号を貫く導体 / 3 線式センサの電源が逆 / ユニット電源の枚が無い / 分かれた枚の行き先が無い** を追加しました (重なりの判定は bounds ではなく**実際に線を引いている範囲**で行います)。

- **PLC 入出力結線図の是正 (批評ラウンド 1 の反映)**: 保護接地の図記号を **02-15-03 (丸囲み)** に直しました (丸のない一般接地 02-15-01 では保護接地を表しません)。見出しの種別が罫線に重なっていたのを直し、**和文が最小呼び 3.5mm で描かれること**を前提に行取りしました。用紙の判定で**改訂履歴欄**も空けるようにし (改訂を 1 行足しただけで図が欄に乗る破綻を防ぎます)、用紙の候補は同じ大きさなら横向きを先に見ます。**機能欄の文言も検図の対象**になり (図枠外・表題欄との重なり)、**保護接地の未接続はエラー**になりました。機器タグは**見出しの左肩に固定**して、現場側の配線区画へ降りないようにしました。

- **PLC 入出力結線図の追加**: キーエンス KV Nano 3 機種の結線図記号を追加しました。あわせて次を直しています — **縮小尺度の検図が「実際に描かれている文字と線」を測って判定する** (今までは尺度だけで決め打ちしていました。破線枠・作図線の細線や、data-h を持たない取り込み文字も測ります)。**未接続ピンの検図をピン単位で除外できる** ようにし、同じ名前の端子が複数ある記号では区分 (列・行) を添えて見分けられるようにしました。**端子番号のラベルが導体を避ける** ようになりました。図枠・表題欄との重なりは、記号が **線を引いている範囲** で見ます。
- **行き先 (継続先) の追加**: 継続表示の記号を追加しました。既存図面には影響しません (新規に置いた行き先が未設定のままだとエラーになります)。あわせて、**電位リンクで葉をまたいでつないだ回路に同じ線番を振っても「線番の重複」を出さなくなりました** (今までは多葉の図で必ず警告が出ていました)。同一ページ内の重複と、無関係な葉での重複は今までどおり検出します。
- **非常停止ボタン (2NC)**: b接点×2を機械リンクで同時に開く2重化シンボル (estop2) を追加。安全リレーの二重化入力用。
