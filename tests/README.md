# 回帰テスト

`index.html` を Playwright (playwright-core) の Chromium で開き、実際の描画と検図を確かめます。
失敗したテストは exit code 1 を返すので、まとめて実行するときは:

```sh
sh tests/run.sh          # Chrome の場所は環境変数 CHROME で上書きできます
```

事前に `npm i playwright-core` した場所へ `tests/node_modules` を用意してください
(このリポジトリは依存ゼロで動くため、テストだけが Node と playwright-core を使います)。

| ファイル | 見ているもの |
| --- | --- |
| `cable-stretch.mjs` | 多芯ケーブル囲み・シールドの伸縮 (寸法違いの生成・保存/再読込・DXF・部品表)、線番の位置 |
| `wire-label-placement.mjs` | 線番の置き方。芯数 {2,4,8,12} × 桁数 {1〜7} × 向き {横,縦} × 長さ {長,短} の 112 通りを列挙し、自分の線の脇にあること・隣の心線に載らないこと・実際の輪郭 (長円) を貫通しないこと・ケーブルの中で列が割れないこと・はみ出しが幾何的な下限以内であることを見る |
| `sheet-orientation.mjs` | 図枠の向き (縦置き/横置き)。作図領域・格子参照の区分数・表題欄の位置と用紙欄の表記・DXF・ページ個別/全ページ既定・保存/読込、そして設定ダイアログから実際に切り替わること |
| `cable-drc.mjs` | 芯数の不一致・遮へいの両端接地/PE 誤接続 (ページをまたぐ場合を含む)・**正しく描いた図では検図が 1 件も出ないこと**・遮へい単体 (シールド線)・部品表で心線囲みと遮へいが 1 行にまとまり長さ (m) が集計されること |
| `comm-ports.mjs` | コントローラの通信ポート (EtherNet/IP・USB-A/B/C・HDMI)。1極のプラグ・ソケット (03-03-05) であること・端子割付が desc に残っていること・受け口の識別図が互いに違う形であること (外形の指紋)・全 path が細線 0.25mm であること・回転 0/90/180/270 で見出しが正立し外接矩形に収まること (画面と DXF の両方)・パレットと図面が同じ図形で倍率が揃っていること・RJ45 を置くと機能テキストに EtherNet/IP が入ること |
| `dxf-dash.mjs` | DXF の遮へいが画面と同じ線種で開けること (実寸の LTYPE・円弧は ARC エンティティ・破線の周期より短い要素が無いこと・画面の外形と一致すること) |
| `goto-ref.mjs` | 行き先 (継続先) 記号。図番が指し先ページのものになること・図番の文字列を焼き付けていないこと (並べ替え/接頭辞変更/ページ個別図番/ページ追加/保存再読込のどれでも追従)・プルダウンで実際に選べて自ページは選べないこと・旗の寸法が M=2.5mm の整数倍で全長が格子 5mm の整数倍であること・図番が平行部の中央にあり五角形の 5 辺から 0.825mm (判読限界 0.7 + 輪郭のインク 0.125) あくこと・外接矩形と中心合わせを実インクで行うこと (和文図番は旗に収まらないのでエラー)・対は信号 (電位リンクのタグ) で決めて区分 (列と行) を書き、定まらなければ図番だけに戻して警告すること・検図 (未設定/自己参照/指し先削除/図番が入らない=エラー、対が無い/対が定まらない/旗の重なり/リンクの不一致=警告)・葉をまたぐ線番を誤警告しないこと・貼り付けで自己参照を残さないこと・DXF (XREF レイヤ・位置と角度・中央寄せの揃え記号)・**シミュレーションに影響しないこと** |
| `plc-io.mjs` | キーエンス KV Nano (KV-N14AT/N24AT/N40AT) の入出力結線図。用紙 1 枚 = 1 群 (16 点まで) で、点数と端子番号が実機どおり 16 点ごとにチャネルが繰り上がること・想定用紙 (1:1。表題欄と改訂履歴欄を空けて選ぶ) の図枠に収まり表題欄を避けること・紙の上の寸法 (行ピッチ 20mm・文字 2.5mm・線 0.25mm) が群によらず同じこと・未使用の入出力点は黙るが電源/コモン/保護接地の未接続は知らせ PE の未接続はエラーで丸囲みの保護接地 02-15-03 が付くこと・見出しの 2 行が箱に収まり罫線とあくこと・行ピッチ 15mm ならすべて A3 横 1:1 に収まること・「下地を作る」が**本物の導体**でレールと各行の分岐を引き二度押しても増えないこと・隙間に機器を置き COM をつなぐと**検図 0 件になり現場機器と PLC 端子が同じネットになる**こと・機能欄の文言が画面と DXF に出て下線の上に載ること (空行は飛ばす)・長すぎる文言が図枠の外へ出たら検図に出ること・プロパティで同じ群の機種に差し替えられ、用紙が変わる差し替えは検図に出て「この用紙にする」で消えること・**行ピッチ (既定 20mm) で横に倒した現場機器の線が隣の行と 0.5mm 以上あくこと** (光電センサのような横に長い記号は既定では当たるが、プロパティで 30mm へ広げれば収まり用紙も選び直されること)・部品表と DXF |
