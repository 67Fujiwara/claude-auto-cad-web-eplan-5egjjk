# 回帰テスト

`index.html` を Playwright (playwright-core) の Chromium で開き、実際の描画と検図を確かめます。
失敗したテストは exit code 1 を返すので、まとめて実行するときは:

```sh
sh tests/run.sh          # Chrome の場所は環境変数 CHROME で上書きできます
```

事前に `npm i playwright-core` した場所へ `tests/node_modules` を用意してください
(このリポジトリは依存ゼロで動くため、テストだけが Node と playwright-core を使います)。

| ファイル | 見ているもの |
| --- | --- |
| `cable-stretch.mjs` | 多芯ケーブル囲み・シールドの伸縮 (寸法違いの生成・保存/再読込・DXF・部品表)、線番の位置 |
| `wire-label-placement.mjs` | 線番の置き方。芯数 {2,4,8,12} × 桁数 {1〜7} × 向き {横,縦} × 長さ {長,短} の 112 通りを列挙し、自分の線の脇にあること・隣の心線に載らないこと・実際の輪郭 (長円) を貫通しないこと・ケーブルの中で列が割れないこと・はみ出しが幾何的な下限以内であることを見る |
| `cable-drc.mjs` | 芯数の不一致・遮へいの両端接地/PE 誤接続 (ページをまたぐ場合を含む)・**正しく描いた図では検図が 1 件も出ないこと**・遮へい単体 (シールド線)・部品表で心線囲みと遮へいが 1 行にまとまり長さ (m) が集計されること |
| `dxf-dash.mjs` | DXF の遮へいが画面と同じ線種で開けること (実寸の LTYPE・円弧は ARC エンティティ・破線の周期より短い要素が無いこと・画面の外形と一致すること) |
